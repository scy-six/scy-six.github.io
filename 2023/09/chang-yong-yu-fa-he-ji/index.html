一、Markdown 常用语法

功能 语法
标题 # 一级 ~ ###### 六级
粗体 **文字**
斜体 *文字*
删除线 ~~文字~~
无序列表 - 项目
有序列表 1. 项目
任务列表 - [x] / - [ ]
链接 [文字](地址)
图片 ![说明](地址)
引用 > 文字
行内代码 `代码`
代码块 ```语言 包裹
分割线 ---
表格 | 表头 | 表头 |
换行 行末两空格 或 <br>
转义 \符号

2. Butterfly 标签插件（文中插入特殊块）

写法 效果
{% note info %}提示内容{% endnote %} 彩色提示块，颜色可换 primary / success / warning / danger
{% btn 'https://example.com', 按钮文字 %} 渲染成可点击按钮

更多写法见文末导航里 Butterfly 官方文档。

三、Git

1. 工作流程

2. 常用操作句式

句式 说明
git clone <url> 克隆远端仓库到本地
git switch -c <name> 创建并切换到新分支
git merge <branch> 把指定分支合并进当前分支
git push -u origin main 首次推送并建立跟踪（之后 git push 即可）
git restore <file> 丢弃工作区改动（checkout -- 的新写法）
git log --oneline --graph 图形化查看提交历史
git tag v1.0 给当前提交打标签

3. .gitignore 语法

写法 含义
node_modules/ 忽略该目录
*.log 忽略所有 .log 文件
!keep.log ! = 例外，不忽略
/dist 只忽略仓库根目录下的 dist
**/temp 忽略任意层级的 temp

四、终端 / Linux 语法（Git Bash 通用）

写法 含义
命令1 && 命令2 前者成功才执行后者
命令1 || 命令2 前者失败才执行后者
命令 > 文件 输出重定向（覆盖写入）
命令 >> 文件 输出重定向（追加）
命令1 | 命令2 管道：前者输出交给后者处理
命令 2>&1 错误输出并入标准输出
chmod 755 x.sh 权限数字：所有者/组/其他 = 7/5/5（r=4、w=2、x=1 相加）
sudo <命令> 以管理员权限执行
tar -czvf a.tar.gz dir/ 打包压缩（-x 换成解包）
apt install <pkg> Debian/Ubuntu 装包（CentOS 用 yum）

五、CMD（Windows 原生）

命令 作用
dir 列目录（相当于 Git Bash 的 ls）
cd /d E:\path 切换目录（/d 连盘符一起切）
md <dir> / rd <dir> 建目录 / 删空目录
del <file> 删除文件
copy / move / ren 复制 / 移动 / 重命名
type <file> 查看文本内容（相当于 cat）
tree /f 树状列出目录结构
ipconfig /all 查看网络配置
ping <host> -t 持续 ping（Ctrl + C 停止）
shutdown -s -t 600 600 秒后关机（shutdown -a 取消）
systeminfo 查看系统信息
cls 清屏

六、HTML

标签 作用
<h1> ~ <h6> 标题（一级到六级）
<p> 段落
<a href="https://...">文字</a> 链接
<img src="图片地址" alt="说明"> 图片
<div> / <span> 块级容器 / 行内容器
<ul><li> / <ol><li> 无序 / 有序列表
<table><tr><th><td> 表格（行 / 表头 / 单元格）
<form> / <input> 表单 / 输入框
<button> 按钮
<br> / <hr> 换行 / 分隔线
<!-- 注释 --> 注释
<header> <nav> <main> <footer> 语义结构标签（替代满屏 div）

p 标签选择器
.class 类选择器（最常用）
#id ID 选择器
div p 后代选择器（div 里的 p）
a:hover 伪类（悬停状态）
li:first-child 第一个子元素

八、JavaScript

语法 说明
let x = 1 / const y = 2 变量 / 常量
`共 ${n} 篇` 模板字符串（变量直接嵌进文字）
const add = (a, b) => a + b 箭头函数
arr.map(x => x * 2) 数组逐项变换
arr.filter(x => x > 0) 数组筛选
arr.forEach(x => console.log(x)) 数组遍历
document.querySelector('.cls') 查找元素
el.addEventListener('click', fn) 绑定事件
document.createElement('div') 创建元素
JSON.parse(s) / JSON.stringify(o) JSON 字符串 ↔ 对象
setTimeout(fn, 1000) 1 秒后执行一次
try { ... } catch (e) { ... } 异常捕获

九、Python

语法 说明
print(f"共 {n} 篇") f-string 格式化输出
nums = [1, 2, 3] / d = {"a": 1} 列表 / 字典
nums[0] / nums[1:3] 取元素 / 切片
for i in range(10): 循环 0~9
def add(a, b=1): return a + b 函数（带默认参数）
with open("f.txt", encoding="utf-8") as f: 读文件（自动关闭，防乱码）
try: ... except Exception as e: 异常捕获
if __name__ == "__main__": 被直接运行时才执行的入口
pip install -r requirements.txt 按清单装依赖

十、C

要点 写法

格式符 %d 整数、%f 浮点、%s 字符串、%c 字符
指针 int *p = &n; —— & 取地址、* 取内容
注释 /* 块注释 */ 与 // 行注释
