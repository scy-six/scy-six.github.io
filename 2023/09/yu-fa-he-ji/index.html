命令 全称 作用
hexo init <folder> init 初始化一个新博客
hexo new "标题" new 新建一篇文章
hexo g generate 生成静态文件到 public/
hexo s server 本地预览（默认 4000 端口）
hexo d deploy 部署到远程服务器
hexo clean clean 清理缓存和 public/
hexo new page "about" new page 新建独立页面（如关于我）
hexo new draft "标题" new draft 新建草稿（不公开显示）
hexo publish "标题" publish 把草稿正式发布出去
hexo list list 列出所有文章/页面等数据
hexo version version 查看 Hexo 版本
hexo --help help 查看全部帮助

hexo s -g # 等于 hexo g 再 hexo s
hexo g -d # 等于 hexo g 再 hexo d
hexo clean && hexo g && hexo s # 清缓存 + 生成 + 本地预览
hexo clean && hexo g && hexo d # 清缓存 + 生成 + 一键部署
