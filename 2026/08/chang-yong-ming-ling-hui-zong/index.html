常用命令汇总

发表于2026-08-31|更新于2026-09-06|学习

一、Git

命令 全称 作用
git status status 查看工作区状态（已修改 / 已暂存 / 未跟踪）
git add <file> add 将文件加入暂存区（-A 全部，. 当前目录）
git commit -m "msg" commit 提交暂存区内容到本地仓库
git push push 推送当前分支到远端
git pull pull 拉取远端最新并合并到当前分支
git log --oneline log 查看提交历史（简洁模式）
git diff diff 查看未暂存的改动
git diff --cached diff cached 查看已暂存的改动
git branch branch 列出本地分支（-a 含远端，-vv 含上游跟踪）
git switch <branch> switch 切换到指定分支（-c <name> 创建并切换）
git checkout -- <file> checkout 丢弃某文件的未暂存改动（⚠️ 不可逆）
git reset HEAD <file> reset 将文件从暂存区撤回（保留磁盘文件）
git rm --cached <file> rm cached 从版本控制中移除但保留磁盘文件
git remote -v remote 查看远端地址
git stash stash 临时保存当前改动（pop 恢复）

⚠️ 本项目严禁 git rm（会导致磁盘文件消失）。安全删除 = rm -f <file> + git add -A

二、Hexo

命令 全称 作用
hexo init <folder> init 初始化一个新博客
hexo new "标题" new 新建一篇文章
hexo g generate 生成静态文件到 public/
hexo s server 本地预览（默认 4000 端口）
hexo d deploy 部署到远程服务器
hexo clean clean 清理缓存和 public/
hexo new page "about" new page 新建独立页面（如关于我）
hexo new draft "标题" new draft 新建草稿（不公开显示）
hexo publish "标题" publish 把草稿正式发布出去
hexo list list 列出所有文章/页面等数据
hexo version version 查看 Hexo 版本
hexo --help help 查看全部帮助

组合用法

本项目 npm 脚本快捷方式

命令 等价操作
npm run build 番剧标题覆盖 → hexo generate → 图片优化 → 相册校验
npm run clean hexo clean
npm run lint ESLint 校验 scripts/ 和 tools/
npm run deploy 网页产物直推 GitHub Pages

改完 scripts/*.js 后必须 rm -f db.json 再 generate，否则缓存导致改动不生效。

三、Python

命令 作用
python script.py 运行脚本
python -m venv venv 创建虚拟环境
venv\Scripts\activate Windows 激活虚拟环境
pip install <pkg> 安装包
pip list 查看已安装包
pip freeze > requirements.txt 导出依赖清单

本项目 Python 用于 tools/gen_*.py 数据管道（运动 / 登山 / 体重 Excel → 页面数据）

四、终端 / 文件操作（Git Bash）

命令 作用
ls -la 列出目录详情（含隐藏文件）
cd <path> 切换目录
pwd 显示当前路径
cat <file> 查看文件内容
head -n <N> <file> 查看文件前 N 行
tail -n <N> <file> 查看文件后 N 行
grep "关键词" <file> 在文件中搜索关键词
grep -rn "关键词" <dir> 递归搜索目录下所有文件
find . -name "*.md" 按名称查找文件
cp <src> <dst> 复制文件 / 目录（-r 递归）
mv <src> <dst> 移动 / 重命名
rm -f <file> 删除文件（⚠️ 不可逆）
mkdir -p <dir> 创建目录（含父目录）
du -sh <dir> 查看目录大小
wc -l <file> 统计文件行数
echo $HOME 显示用户主目录
which <cmd> 查找命令所在路径
chmod +x <file> 添加执行权限
