人生测算工具清单

发表于2026-10-08|更新于2026-10-17|生活

把生活和工作里的大事算成账、把”自己”测成数据的在线工具汇总，共六类：职场、财务、性格、能力、心理、生活。

提示：部分在线工具可能已下线或停止维护，如遇无法访问的情况请尝试搜索替代工具。
以下工具均为免费使用。
⚠ 能力测评与心理量表只作自我了解的参考，不等于诊断结论；情绪困扰明显时请优先咨询专业机构。

一、职场工作

围绕”上班”这件事的测算：薪资性价比、跨城 Offer 对比、离职补偿、摸鱼减压等。

工具 说明 渠道 测算网址
这 b 班上得值不值 综合薪资、工时、通勤等因素折算工作性价比评级 github 打开
城市 Offer 薪资对比 按生活方式换算不同城市间的等价薪资与倍率 github 打开
职场计算器全家桶 税后工资、个税、房贷、离职补偿、Offer 对比等职场计算 微信小程序 微信内搜索同名小程序
在线求生资源集合 职场求生工具集合，含离职倒计时、减压工具与求职资源 AntiWork 不想工作网 打开

二、财务计算

围绕”花钱 / 省钱”的测算：个税社保、房贷租房、婚嫁养车、养老金等。

工具 说明 渠道 测算网址
个人财物与精算 个税、社保、房贷、理财、离职成本等个人财务计算工具集 GFWPS 财务精算平台 打开
租房买房对比 买房 vs 租房的盈亏平衡年份测算 NowTo Money 理财计算站 打开
结婚费用计算器 婚嫁总开销与礼金抵扣后的真实净支出 xantool 在线工具箱 打开

三、性格测试

围绕”我是谁”的测算：人格类型、认知功能、心理特质等。

工具 说明 渠道 测算网址
OSJJ 开源荣格十六型人格测试，48 题，完全免费匿名 OSJJ 打开
Sakinorva 开源荣格八维认知功能测试，学术向，多算法交叉验证 Sakinorva 打开
BigFive Personality Test 开源大五人格测试，基于心理学五大特质模型 github 打开
16Personalities 全球知名性格测试，有中文，基于大五人格模型 16Personalities 打开
Open Psychometrics 非盈利开源心理测试平台，提供多种人格与心理量表 Open Psychometrics 打开

四、能力测评

围绕”我能干什么”的测算：职业兴趣、职业能力、认知能力，全部免费，尽量选有官方或学术机构背书的。

工具 说明 渠道 测算网址
O*NET 兴趣测评 美国劳工部 O*NET 官方，霍兰德六型，约 6 分钟出报告，免费免注册 O*NET / My Next Move 打开
学职平台职业测评 教育部学生服务与素质发展中心主办，兴趣 / 性格 / 能力 / 价值观等多类测评，学信网账号登录免费 学职平台（学信网） 打开
国家大学生就业服务平台测评 教育部主管，面向高校毕业生的免费职业测评 24365 国家大学生就业服务平台 打开
北京人社职业测评 北京市人社局公共服务平台「就业在北京」，含职业能力 / 素质测评，免费 北京市人社公共服务平台 打开
深圳人社人才测评 深圳市人社局官方，一次覆盖认知、性格、情商、心理健康等，免费 深圳人力资源生态服务平台 打开
CEST 认知实验标准工具箱 中科院心理所出品，覆盖注意 / 执行功能 / 工作记忆 / 处理速度 / 语言等，有中国人群常模，在线施测免费 中科院心理所 打开
BoCA 波士顿认知评估 临床研究级数字化认知测评，约 10 分钟覆盖多个认知域，即时出结果 Boston Cognitive 打开
TestMyBrain 学术团队维护的免费认知测试集，测记忆 / 注意 / 推理等，数据用于科研 TestMyBrain 打开
ICAR 国际认知能力资源 公共域开源认知能力题库，研究级、有常模参照，可自测 ICAR Project 打开
Human Benchmark 免费小游戏式测试（反应 / 记忆 / 数字 / 言语），有全球排名、无常模，适合作个人基线 Human Benchmark 打开

选测建议：有常模、有机构背书的优先（O*NET / 学职平台 / CEST / BoCA）；Human Benchmark 这类只适合看自己随时间的变化，不宜当”能力分数”解读。
