常用快捷键汇总

发表于2026-10-05|更新于2026-10-05|学习

资料来源：Microsoft 官方支持文档《Microsoft Edge 中的键盘快捷方式》+ 本机整理的《电脑快捷键》笔记。
说明：Mac 平台多数以 ⌘ Command 替换 Ctrl、以 ⌥ Option 替换 Alt，下文在常用项后附 Mac 等价写法；未标注者以 Windows 为准。

一、Windows 系统通用

1. Ctrl 组合（编辑 / 窗口）

快捷键 作用
Ctrl + A 选择所有文本 / 项目
Ctrl + Z 撤消操作
Ctrl + Y 重做操作
Ctrl + C 复制选定项
Ctrl + X 剪切选定项
Ctrl + V 粘贴选定项
Ctrl + Shift + V 不带格式粘贴（网页 / 编辑器）
Ctrl + D / Delete 删除选定项并移入回收站
Ctrl + F 系统 / 软件 / 网页查找
Ctrl + H Edge 历史记录（见第二节）
Ctrl + Alt + Tab 显示当前桌面运行的所有应用
Ctrl + Shift + Esc 打开任务管理器
Ctrl + Shift + 左/右箭头 以整词为单位向左 / 右扩展选择
Ctrl + Shift + Home/End 从光标选到窗口开头 / 结尾
Ctrl + PageUp / PageDown 光标向上 / 下滚动一页

2. Alt 组合

快捷键 作用
Alt + F4 关闭活动项目；桌面为空时打开关机菜单
Alt + Tab 在已打开窗口间切换

3. Shift 组合（选区）

快捷键 作用
Shift + 方向键 向四个方向移动光标并同时选择文本
Shift + Home / End 从光标选到当前段落开头 / 结尾
Shift + PageUp / PageDown 从光标选到页面起 / 止

4. Win 键（系统 / 多桌面 / 窗口排布）

快捷键 作用
Win + E 打开文件资源管理器
Win + I 打开设置
Win + A 打开操作中心侧边栏
Win + N 打开通知中心 / 日历
Win + X 打开系统右键菜单（即右键”开始”）
Win + R 运行对话框（如 shell:startup 改开机启动项；ipconfig 查 IPv4）
Win + L 锁定电脑 / 切换账户
Win + D 显示桌面 / 恢复窗口
Win + M 最小化所有窗口
Win + ← / → 将当前窗口贴靠到屏幕左 / 右半边
Win + ↑ / ↓ 最大化 / 最小化当前窗口
Win + P 扩展屏幕 / 投影
Win + T 选择任务栏上的应用
Win + 数字 打开任务栏从左到右第 N 个应用（不含开始图标）
Win + Q / Win + S 搜索
Win + V 打开剪贴板历史
Win + Tab 显示所有运行程序与虚拟桌面
Win + Ctrl + D 新建虚拟桌面
Win + Ctrl + ← / → 切换虚拟桌面
Win + Ctrl + F4 关闭当前虚拟桌面
Win + PrtScr 截取全屏并保存到”图片”文件夹
Win + PauseBreak 打开系统控制面板

关机 / 重启命令（在 Win + R 中执行）：shutdown -s -t 600（600 秒后关机）、shutdown -a（取消定时关机）、shutdown -r -t 600（600 秒后重启）。

5. 功能键 Fx

快捷键 作用
F2 重命名选定项
F3 在文件资源管理器中搜索
F4 在文件资源管理器中显示地址栏列表
F5 刷新活动窗口

6. 截图 / 录屏（软件相关，非系统原生）

以下多为第三方工具（如联想电脑管家 / 截图软件）绑定，系统本身无此默认映射。

快捷键 作用
PrtScr 仅截取当前屏幕，不自动保存
Alt + S 录屏
Alt + W 文字识别
Alt + D 截图翻译
Ctrl + Q 截屏

二、Microsoft Edge 浏览器快捷键

官方文档同时给出 Windows / Mac 写法；下表以 Windows 为主，Mac 等价写在括注，通用项（如 F5、Esc）不重复标注。

1. 标签页

快捷键 (Win) Mac 等价 作用
Ctrl + T ⌘ + T 打开新标签页并切换
Ctrl + Shift + T ⌘ + Shift + T 重新打开刚关闭的标签页
Ctrl + W / Ctrl + F4 ⌘ + W 关闭当前标签页
Ctrl + Shift + K — 复制当前标签页
Ctrl + M Ctrl + M 切换当前标签页静音
Ctrl + 1…8 ⌘ + 1…8 切换到指定位置标签页
Ctrl + 9 ⌘ + 9 切换到最后一个标签页
Ctrl + Tab / Ctrl + PageDown ⌘ + Fn + ↓ 切换到下一个标签页
Ctrl + Shift + Tab / Ctrl + PageUp ⌘ + Fn + ↑ 切换到上一个标签页

2. 窗口 / 全屏 / 退出

快捷键 (Win) Mac 等价 作用
Ctrl + N ⌘ + N 打开新窗口
Ctrl + Shift + N ⌘ + Shift + N 打开 InPrivate 新窗口
Ctrl + Shift + W / Alt + F4 ⌘ + Shift + W 关闭当前窗口
F11 ⌘ + Ctrl + F 进入 / 退出全屏（Mac 全屏下 Esc 退出）
— ⌘ + M / ⌘ + Q 最小化窗口 / 退出 Edge

3. 地址栏与搜索

快捷键 (Win) Mac 等价 作用
Alt + D / Ctrl + L / F4 ⌘ + L 选中地址栏 URL 以编辑
Ctrl + E / Ctrl + K ⌘ + Option + F 在地址栏打开搜索查询
Ctrl + Shift + E ⌘ + Shift + E 在侧栏打开搜索
Ctrl + Shift + L — 粘贴并搜索 / 粘贴并访问（若为 URL）
Ctrl + Enter ⌘ + 回车 自动补全 www. 与 .com

4. 导航与页面滚动

快捷键 (Win) Mac 等价 作用
Alt + ← ⌘ + [ 后退
Alt + → ⌘ + ] 前进
Alt + Home ⌘ + Shift + H 在当前标签打开主页
Home / End — 跳到页面顶部 / 底部
空格 / PageDown 空格 向下滚动一屏
Shift + 空格 / PageUp Shift + 空格 向上滚动一屏

5. 阅读 / 缩放 / PDF

快捷键 (Win) Mac 等价 作用
Ctrl + Shift + U ⌘ + Shift + U 开始 / 停止”大声朗读”
F9 F9 进入 / 退出沉浸式阅读器
F7 — 打开 / 关闭光标浏览
Ctrl + 0 ⌘ + 0 重置页面缩放
Ctrl + + ⌘ + + 放大
Ctrl + - ⌘ + - 缩小
Ctrl + \（PDF） ⌘ + \ PDF 在”适应页面 / 适应宽度”间切换
Ctrl + [ / Ctrl + ]（PDF） ⌘ + [ / ⌘ + ] PDF 逆时针 / 顺时针旋转 90°

6. 历史 / 下载 / 集合 / 清除数据

快捷键 (Win) Mac 等价 作用
Ctrl + H ⌘ + Y 打开历史记录
Ctrl + J ⌘ + Option + L 打开下载
Ctrl + Shift + Y — 打开收藏集
Ctrl + Shift + Delete ⌘ + Shift + 删除 打开”清除浏览数据”

7. 查找 / 编辑 / 剪贴板

快捷键 (Win) Mac 等价 作用
Ctrl + F / F3 ⌘ + F 在页面打开查找
Ctrl + G ⌘ + G 跳到下一个查找结果
Ctrl + Shift + G ⌘ + Shift + G 跳到上一个查找结果
Ctrl + Shift + V ⌘ + Shift + V 无格式粘贴

8. 开发工具

快捷键 (Win) Mac 等价 作用
Ctrl + Shift + I / F12 ⌘ + Option + C / F12 打开开发人员工具
Ctrl + U ⌘ + Option + J 查看源代码 / 打开 JS 控制台

9. 打印 / 保存 / 刷新

快捷键 (Win) Mac 等价 作用
Ctrl + P ⌘ + P 打印当前页
Ctrl + Shift + P — 用系统对话框打印
Ctrl + S ⌘ + S 保存当前页
Ctrl + O ⌘ + O 在 Edge 中打开本地文件
Ctrl + R / F5 ⌘ + R 重新加载当前页
Ctrl + Shift + R / Shift + F5 ⌘ + Shift + R 忽略缓存重新加载

10. 设置 / 帮助 / 菜单

快捷键 (Win) Mac 等价 作用
Alt + E / Alt + F — 打开”设置及更多”菜单
Alt / F10 — 将焦点放到”设置及更多”按钮
Shift + F10 — 打开上下文菜单
Alt + Shift + I — 打开”发送反馈”
F1 — 打开帮助
Esc Esc 停止加载 / 关闭对话框或弹窗

三、速记口诀

  • 关标签 → Ctrl + W；开标签 → Ctrl + T；手滑关了 → Ctrl + Shift + T
  • 找东西 → Ctrl + F；看历史 → Ctrl + H；看下载 → Ctrl + J
  • 回桌面 → Win + D；锁屏 → Win + L；分屏 → Win + ←/→
  • 刷新 → F5 / Ctrl + R；强制刷新 → Ctrl + Shift + R
  • 开发者 → F12；全屏 → F11
