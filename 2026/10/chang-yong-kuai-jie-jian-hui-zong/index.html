常用快捷键汇总

发表于2026-10-05|更新于2026-10-05|学习

资料来源：Microsoft 官方支持文档《Microsoft Edge 中的键盘快捷方式》+ 本机整理的《电脑快捷键》笔记。
说明：只保留日常高频项；Edge 完整列表见文末导航的官方文档。

一、Windows 系统通用

1. Ctrl 组合（编辑 / 文档）

快捷键 作用
Ctrl + C / X / V 复制 / 剪切 / 粘贴
Ctrl + Shift + V 不带格式粘贴
Ctrl + A 全选
Ctrl + Z / Ctrl + Y 撤销 / 重做
Ctrl + S 保存
Ctrl + P 打印
Ctrl + N 新建（文档 / 窗口）
Ctrl + O 打开文件
Ctrl + B / Ctrl + I / Ctrl + U 加粗 / 斜体 / 下划线（编辑器中）
Ctrl + F 查找
Ctrl + H 替换（编辑器中）/ 历史（浏览器，见第二节）
Ctrl + Home / Ctrl + End 跳到文档开头 / 结尾
Ctrl + Shift + 左/右箭头 以整词为单位选中
Ctrl + Backspace 删除光标前一个词
Ctrl + Shift + Esc 直接打开任务管理器
Ctrl + Alt + Del 系统安全界面（锁定 / 任务管理器 / 注销）

2. Alt / Shift 组合

快捷键 作用
Alt + Tab 在已打开窗口间切换
Alt + F4 关闭当前程序；桌面为空时弹出关机菜单
Shift + 方向键 移动光标并选中
Shift + Home / End 从光标选到行首 / 行尾

3. Win 键（系统 / 窗口）

快捷键 作用
Win + D 显示桌面 / 恢复窗口
Win + E 打开文件资源管理器
Win + L 锁定电脑
Win + I 打开设置
Win + A 快捷设置（音量 / 亮度 / 网络）
Win + R 运行对话框（如 ipconfig 查 IPv4）
Win + X 开始按钮右键菜单
Win + ← / → 窗口贴靠左 / 右半屏
Win + ↑ / ↓ 最大化 / 还原 / 最小化
Win + Shift + S 系统截图（区域 / 窗口 / 全屏）
Win + V 剪贴板历史
Win + . Emoji / 特殊符号面板
Win + Tab 任务视图（所有窗口总览）
Win + 数字 打开任务栏第 N 个应用
Win + Q / Win + S 搜索

关机 / 重启（在 Win + R 中执行）：shutdown -s -t 600（600 秒后关机）、shutdown -a（取消）、shutdown -r -t 600（重启）。

4. 功能键

快捷键 作用
F2 重命名选定项
F5 刷新

5. 截图 / 录屏（第三方软件绑定，非系统原生）

以下为联想电脑管家等第三方工具的绑定，换电脑可能失效。

快捷键 作用
PrtScr 截取当前屏幕，不自动保存
Alt + S 录屏
Alt + W 文字识别
Alt + D 截图翻译
Ctrl + Q 截屏

二、Microsoft Edge 高频快捷键（Windows）

1. 标签页

快捷键 作用
Ctrl + T 新建标签页
Ctrl + Shift + T 恢复刚关闭的标签页
Ctrl + W / Ctrl + F4 关闭当前标签页
Ctrl + Tab / Ctrl + Shift + Tab 下一个 / 上一个标签页
Ctrl + 1…8 跳到第 N 个标签页
Ctrl + 9 跳到最后一个标签页

2. 窗口 / 全屏

快捷键 作用
Ctrl + N 新窗口
Ctrl + Shift + N InPrivate 无痕窗口
F11 进入 / 退出全屏

3. 地址栏

快捷键 作用
Ctrl + L / Alt + D 选中地址栏
Ctrl + E / Ctrl + K 地址栏直接搜索
Ctrl + Enter 自动补全 www. 与 .com

4. 页面浏览

快捷键 作用
Alt + ← / Alt + → 后退 / 前进
空格 / PageDown 下翻一屏
Shift + 空格 上翻一屏
Home / End 页面顶部 / 底部

5. 收藏 / 历史 / 下载

快捷键 作用
Ctrl + D 添加收藏
Ctrl + H 历史记录
Ctrl + J 下载内容
Ctrl + Shift + Delete 清除浏览数据

6. 刷新 / 缩放 / 查找 / 保存

快捷键 作用
F5 / Ctrl + R 刷新页面
Ctrl + Shift + R 忽略缓存强制刷新
Ctrl + + / Ctrl + - / Ctrl + 0 放大 / 缩小 / 重置缩放
Ctrl + F 页内查找
Ctrl + S 保存页面
Ctrl + P 打印
F12 开发者工具

三、速记口诀

  • 截图 → Win + Shift + S；录屏 → Alt + S；文字识别 → Alt + W
  • 锁屏 → Win + L；回桌面 → Win + D；分屏 → Win + ←/→
  • 关标签 → Ctrl + W；开标签 → Ctrl + T；手滑关了 → Ctrl + Shift + T
  • 刷新 → F5；强制刷新 → Ctrl + Shift + R；全屏 → F11
  • 找东西 → Ctrl + F；看历史 → Ctrl + H；看下载 → Ctrl + J
  • 开发者 → F12；任务管理器 → Ctrl + Shift + Esc
