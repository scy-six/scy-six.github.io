## 一、网页概览

Scy's Blog 是一个个人静态博客，承载三方面内容：

| 板块 | 内容 |
| ---- | ---- |
| **博客文章** | 电脑配置、装机清单等文章 |
| **兴趣记录** | 追番列表、QQ 空间说说档案、运动记录、登山记录、旅行相册 |
| **照片相册** | 宠物、花园、DIY、观鸟、钓鱼 等相册 |

网页为纯静态页面，所有图片、脚本、样式均**自托管同源可用**（第三方库已下载到 `pluginsSrc/` 本地加载，不依赖 jsDelivr 等外部 CDN），无外部统计与评论服务。

## 三、各页面内容

### 3.1 博客文章

- 文章列表 + 按分类归档
- 文章正文含表格、代码块、图片灯箱等排版

### 3.2 第三次元（追番列表）

- 按「想看 / 在看 / 看过」三个标签分类展示追番
- 以网格视图展示，标题悬停显示完整名称
- 每条番剧展示封面、类型、评分、进度与个人短评

### 3.3 此去经年（QQ 空间说说）

- 把当年的 QQ 空间说说按 **年 → 月 → 日** 三级归档展示
- 默认折叠、最新年份自动展开；点击年份标题或右侧目录可展开/收起整年
- 说说含正文、配图灯箱、评论互动、emoji 与 @ 提及链接

### 3.4 修身养性（运动记录）

- 概览：游泳 / 骑行 / 跑步三项统计卡（次数、投入时长）
- 运动记录：三项速率折线图（跑步/骑行 km/h、游泳配速 min/100m）
- 累计趋势：三项累计距离折线图
- 质量监控：体重趋势折线图
- 图表为手绘 SVG，坐标轴自动取整，悬停有数值提示

### 3.5 十万大山（登山记录）

- 登山数据折线图与登顶记录

### 3.6 到此一游（旅行）

- 按目的地分组的旅行照片墙，点击放大灯箱浏览

### 3.7 五个相册

- 宠物（按主题文件夹）、花园（按日期）、DIY、观鸟、钓鱼
- 统一网格布局，照片点击灯箱放大；文件名显示在照片底部（半透明渐变条）
- 相册内部还分子相册时（如宠物相册的「中心社区 → 设备物资 / 社区成员」）：页面顶部是**相册菜单**，鼠标悬停（或键盘聚焦）即展开下拉列出子相册——点相册名看该相册自身的照片，点下拉项只看该子相册；**子相册不再另开网址**，切换都在同一页内完成，无需下滑
- 照片由维护者从本地照片库**手动同步**后随站点发布（同步与站点渲染分离，照片不会自动更新）

### 3.8 关于

- 作者头像与信息卡
- 技能专长（学科能力 / 计算机能力 / 兴趣爱好，双列进度条）
- 建站历程时间线、十年之约

## 四、页面数据与更新

网页为静态站点，内容更新后需重新构建并部署才会生效。各页面的数据来源与更新方式不同：

| 页面 | 数据来源 | 更新方式 |
| ---- | ---- | ---- |
| 第三次元 | AniList 追番收藏 | 维护者拉取数据后重建（**不会自动同步**） |
| 此去经年 | 本地说说存档（Markdown） | 编辑存档文件后重建 |
| 修身养性 / 十万大山 | 本地运动 / 登山记录表 | 更新表格 → 生成数据 → 重建 |
| 到此一游 | 手工维护的旅行照片页 | 手工增删后重建 |
| 五个相册 | 本地照片库 | 手动同步后重建 |

## 五、网页视觉风格

| 特点 | 说明 |
| ---- | ---- |
| 配色 | 自然系青绿主色（`#2F6E63`）+ 卡片式内容区，亮色 / 暗色模式自动适配 |
| 明暗模式 | 按时间自动切换：**08:00–21:59 亮色**、**22:00–07:59 暗色**；也可点右上按钮手动切换（手动选择会被记住，优先级高于时间规则） |
| 背景壁纸 | 随明暗模式联动：亮色 `wallpaper.webp`、暗色 `wall.webp`；首屏由同步脚本注入，无白闪 |
| 副标题框 | 多数页面顶部有一段主题式副标题（如「生命不息，追番不止」），带引号装饰 |
| 表格 | 圆角卡片 + 渐变表头 + 斑马纹 + 行悬停高亮 |
| 代码 / 引用 | 统一样式：代码块圆角、行内代码高亮、引用块主色竖线 |
| 图片 | 全站统一灯箱放大浏览，加载有占位 |
| 标题 | 各页面正文标题前有链接图标，年份折叠有三角指示 |
