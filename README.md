## 一、网页概览

Scy's Blog 是一个个人静态博客，承载三方面内容：

| 板块 | 内容 |
| ---- | ---- |
| **博客文章** | 电脑、文摘、摄影、学习、生活 等 |
| **兴趣记录** | 追番列表、说说档案、运动记录、登山记录、旅行记录 等 |
| **照片相册** | 宠物、花园、DIY、摄影、钓鱼 等相册 |

网页所有图片、脚本、样式均自托管同源加载；无评论系统，访客统计使用 Vercount（第三方服务）。

## 三、各页面内容

### 3.1 首页：树状导航图

- 首页主体是一张**树状导航图**：以「分类 / 相册清单 / 单页」为三大板块，把全站内容画成一棵树
- 节点与连线**自动生成**：新增分类或页面，树上自动长出新节点（连线为 SVG 实时绘制）
- 点击任意节点直达对应页面；分类节点可展开/折叠

### 3.2 博客文章

- 分类经导航栏「分类」下拉进入，各分类页列出该分类下的全部文章
- 文章正文含表格、代码块、图片灯箱等排版

### 3.3 第三次元（追番列表）

- 按「想看 / 在看 / 看过」三个标签分类展示追番
- 以网格视图展示，标题悬停显示完整名称
- 每条番剧展示封面、类型、评分、进度与个人短评
- 页面副标题：「生命不息，追番不止！」

### 3.4 此去经年（说说档案）

- 把 QQ 空间说说按 **年** 归档展示，最新年份默认展开，点击年份标题可折叠/展开整年
- 每条说说带完整日期（年-月-日）、正文、配图灯箱，支持 emoji 与 @ 提及

### 3.5 修身养性（运动记录）

- 概览：运动项目 / 运动次数 / 投入时长 三张统计卡
- 运动记录：跑步、骑行、游泳各自「速率（游泳为配速）/ 距离」两张同款折线图
- 质量监控：体重趋势折线图（kg，自高中至今），不含辅助参数
- 图表为手绘 SVG，坐标轴自动取整，悬停有数值提示

### 3.6 十万大山（登山记录）

- 登顶山峰 / 攀登次数 / 里程合计 三张统计卡
- 攀登记录表（登顶记录）+ 距离对比柱状图 + 累计攀登折线图

### 3.7 到此一游（旅行记录）

- 足迹地图（中国地图标注到访地）+ 足迹概览统计卡
- 按目的地 / 年份分组的旅行照片墙，点击放大灯箱浏览

### 3.8 五个相册

- 宠物、花园、DIY、摄影、钓鱼
- 统一网格布局，照片点击灯箱放大；文件名显示在照片底部（半透明渐变条）
- 相册内部还分子相册时（如宠物相册的「中心社区 → 设备物资 / 社区成员」）：页面顶部是**相册菜单**，鼠标悬停（或键盘聚焦）即展开下拉列出子相册——点相册名看该相册自身的照片，点下拉项只看该子相册；**子相册不再另开网址**，切换都在同一页内完成，无需下滑

### 3.9 关于

- 作者信息卡（网名 / 身份与职业 / 所在地 / 当前状态）
- 技能专长（学科能力 / 计算机能力 / 兴趣爱好，双列进度条）
- 建站历程时间线（含**曾用域名**一览）
- 十年之约（建站十年之期，截图留档）
- 友情链接：
  - **工具**：Hexo、Butterfly 主题、建站与魔改教程 等
  - **博客**：常读的博主站点

### 3.10 404 页面

- 走丢啦：动图 + 一句话吐槽，全站任意无效地址都会落到这页

## 四、侧栏与通用交互

### 4.1 侧栏功能卡

| 卡片 | 内容 |
| ---- | ---- |
| **作者信息** | 头像、网名、社交入口 |
| **公告** | 站务通知一句话 |
| **站点延迟** | 实时监测各镜像站点的访问延迟，绿 / 黄 / 红三档显示，可手动重新测速 |
| **网站信息** | 文章数、建站运行天数、访客数与浏览量统计 |

### 4.2 通用交互

- 右下角按钮：**深色模式切换**、**侧栏折叠 / 展开**、**回到顶部**（文章页另有移动端目录按钮）
- 图片懒加载；站内跳转按需预加载
- 全站无障碍支持键盘聚焦；相册照片均有说明文字
